## Not a bug: "a subagent's compact_boundary may count as the parent's"

The operator asked what this item meant (6b22682b), so I checked it before explaining. Verified in
the CLI the fleet runs (claude-agent-sdk 0.3.280, the darwin-arm64 binary): the Agent tool hands
every message its subagent produces to one onMessage handler, and that handler passes on to the
parent only api_error (turned into agent_api_retry progress), bash/powershell progress, nested
agent/skill progress (only with forwardSubagentText), and the subagent's assistant/user messages
(tool_use/tool_result blocks only, unless forwardSubagentText). Every other system message,
compact_boundary and status included, is dropped before the parent's stream. silicyte never sets
forwardSubagentText, and it would not pass compact_boundary anyway. So compaction.compacted() only
ever hears the session's own compaction. Nothing to fix. Re-check only after an SDK upgrade.
